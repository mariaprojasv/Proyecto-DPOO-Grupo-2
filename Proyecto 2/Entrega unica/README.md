# Club Deportivo Séneca — Proyecto 1, versión limpia R64

## Contenido de la entrega
- `src/`: implementación Java del club.
- `test/pruebas/`: pruebas JUnit 5 de reglas y escenarios de usuario.
- `Diagrama_Diseno_Final_Editable.drawio`: diagrama editable con vistas detalladas por paquete y relaciones entre paquetes.
- `REQUISITOS_Y_PRUEBAS.md`: relación orientativa de requisitos y pruebas.
- `PERSISTENCIA_ARCHIVOS_R63.md`: documentación de almacenamiento.
- `CIERRE_PRIMERA_PARTE_R63.md`: auditoría técnica anterior y sus limitaciones.
- `REVISION_ENTREGA_R64.md`: comprobaciones finales y asuntos que no se deben dar por certificados.
- `.project`, `.classpath`: configuración de Eclipse.
- `pom.xml`: configuración alternativa de Maven y JUnit 5; se conserva por ser útil y no interferir con Eclipse.

## Importar y ejecutar en Eclipse
1. File → Import → General → Existing Projects into Workspace.
2. Elegir esta carpeta y confirmar Java 11 o superior.
3. Ejecutar el paquete `test/pruebas` con Run As → JUnit Test.
